## How I work

- **Start from the problem.** Talk it through, then write a PRD with clear goals and non-goals.
- **Design the decisions, not just the screens.** Most of the value is in deciding what to build and what to leave out.
- **Build in small, testable steps with AI.** I use Claude Code as my engineering partner, with a project context file so every session picks up where the last one ended.
- **Ship it for real.** Landing pages, waitlists, payments, backend and all.
